# Marketplace + Delivery (Kafka, DDD, Choreography)

Монорепозиторий учебного проекта для курса КПО. Два независимых сервиса,
которые общаются **асинхронно через Kafka** и вместе демонстрируют материал
лекций 1–6: SOLID, DI, unit-тесты, порождающие, поведенческие и структурные
паттерны, DDD, микросервисы.

## 🎯 Что это

**Marketplace** — маркетплейс по продаже автомобилей. Продавцы публикуют
объявления, покупатели покупают машины, платформа берёт комиссию.

**Delivery** — микросервис доставки. Когда машина продана, marketplace
**публикует событие** `ListingSold` в Kafka. Delivery **читает** это событие,
создаёт доставку и **публикует** `DeliveryScheduled`. Marketplace читает его
обратно и обновляет объявление.

**Зачем два сервиса.** Один сервис не может показать все паттерны из лекций 4–6
органично. Marketplace — домен машин и объявлений, delivery — домен маршрутов и
доставки. Вместе они покрывают материал курса и дают естественный повод
для **микросервисного взаимодействия через события**.

**Ключевая идея.** Каждый паттерн появляется **там, где была конкретная боль**.
Не «на будущее». Это YAGNI.

## 🚀 Быстрый старт

### Всё в Docker

```bash
make up        # kafka, kafka-ui, 2 postgres, delivery, marketplace
make smoke     # полный сценарий: создать → опубликовать → продать → доставить
make down      # остановить
make clean     # остановить + сбросить volumes (БД + Kafka)
